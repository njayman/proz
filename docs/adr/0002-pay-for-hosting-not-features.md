# Pay for hosting, not for features

The paid layer is our hosted cloud only: sync, email relay and the phone app backend, run by us. The binary stays fully GPL v3, with no license keys and no calls home, and the self-hosted v2 server has every feature the hosted one has. We chose this over paid features in the binary because a closed or keyed component would break local-first, make agents depend on license state, and lose free code signing through SignPath Foundation, which only signs fully open-source projects.
