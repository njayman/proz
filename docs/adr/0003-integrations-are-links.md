# Integrations are links; agents do the reading

A project links to the trackers and brains it uses with `{kind, provider, ref}`: the kind (tracker or brain), a provider inferred from the URL host, and the canonical web URL or a local path. proz never calls a third-party API and stores no tokens or endpoint URLs; agents read and write those tools through their own MCP servers, and record results in proz as milestones. We chose this over built-in API clients because every major tracker now runs an official hosted MCP server with OAuth, their endpoints changed often in 2026, and API clients in core would break local-first, mean holding credentials, and make proz maintain one adapter per provider. The cost is that remote work only reaches proz when an agent records it: remote links never produce activity on their own, while local brain paths count file changes like folders do.
